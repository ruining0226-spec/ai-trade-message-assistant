# 第一版产品需求

## 产品定位

AI 外贸开发信助手服务于 B2B 空压机海外客户开发。核心价值是把分散在 LinkedIn、公司主页和官网截图中的信息，转化为经人工确认的客户档案和有依据、不过度承诺的个性化开发信。

## 第一阶段范围

完整流程为：上传一张或多张截图 → 模拟分析 → 确认客户资料 → 配置生成条件 → 生成中英文开发信 → 在线编辑与复制 → 保存版本和任务 → 从历史任务继续编辑。

功能模块：

- 工作台：今日分析、本周生成、待发送、待跟进、最近任务。
- 新建任务：四步工作流、上传校验、模拟分析、人工确认、生成配置、结果编辑。
- 版本管理：保存、重新生成和语气/长度调整均创建新版本，可切换最终选中版本。
- 历史任务：搜索筛选、查看、编辑、复制、状态、跟进日期、备注、归档、二次确认删除。
- 客户管理：从任务汇总，按客户姓名和公司名称去重。
- 资料库：可编辑公司资料和四种演示产品，提供禁止虚构和承诺边界。

## 内容原则

先谈客户行业与业务，再自然联系压缩空气场景；不直接硬推销，不虚构需求、参数、认证、案例或合作关系；以自然问题开启交流；所有推测必须保留不确定性提示。

## 数据与验收

第一阶段使用浏览器 localStorage，刷新后数据仍在。页面支持桌面优先和基本移动端适配。核心页面可访问，完整流程可点击，复制有反馈，删除有确认，并通过 Lint、类型检查和生产构建。

## 暂缓功能

真实视觉/文本 AI、Supabase、LinkedIn 登录或抓取、自动发送、邮件群发、浏览器插件、团队权限、复杂 CRM、付费、手机 App 和云端部署均不在第一阶段范围。
