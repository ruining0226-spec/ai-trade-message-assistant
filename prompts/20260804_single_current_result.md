# 单一当前生成结果

## 目标

- 取消结果页多版本记录、选择和切换交互。
- 每个任务只保存一份当前最新生成结果。
- 首次生成保存当前结果；手动编辑、重新生成和现有改写操作直接覆盖当前结果。
- 保持客户分析、开发信内容、事实与推测、置信度、安全规则和现有视觉风格不变。

## 限制

- 不修改豆包 API 调用方式，不增加 AI 优化请求。
- 不重构无关页面、侧边导航、颜色、字体或卡片体系。
- 不修改 localStorage 键，不进行大规模任务数据迁移。
- 不读取或记录密钥，不提交或推送 Git。

## 实现

- 保留 `Task.versions` 和 `selectedVersionId` 作为旧数据兼容外壳，但新任务始终只保存一个元素。
- 任务向导使用单一 `currentVersion` 状态；所有保存动作通过 `persistCurrentResult` 覆盖当前结果。
- 旧任务加载时优先取原 `selectedVersionId` 对应结果；不存在时取数组最后一项，并归一化为单一结果。
- 删除版本记录卡片和版本切换处理，保留右侧写作护栏卡片，维持原有布局比例。

## 验收

- 结果页不显示版本记录，无法切换历史版本。
- 编辑保存、重新生成不会增加数组长度。
- 旧多版本任务可以打开，并展示原已选或最新结果。
- lint、类型检查、自动测试和 build 全部通过。
