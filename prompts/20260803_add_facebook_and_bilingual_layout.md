# 2026-08-03 增加 Facebook 渠道与中英文对照排版

## 任务范围

在现有 `ai-trade-message-assistant` 第一阶段演示版上进行小范围优化，不重构、不重新初始化，不修改第1步上传截图和第2步确认客户资料，也不调整导航、工作台、公司资料、产品资料、客户管理及历史版本机制。

## 功能要求

1. 第3步联系渠道在 LinkedIn、Email、WhatsApp 基础上增加 Facebook，顺序为 LinkedIn、Facebook、Email、WhatsApp。
2. Facebook 必须贯通 TypeScript 类型、任务结构、localStorage、生成、历史显示、筛选、详情、复制、刷新和重新打开。
3. 四个渠道分别生成适合平台的内容：
   - LinkedIn：连接邀请、连接后的第一封消息。
   - Facebook：首次联系消息、回应或建立联系后的跟进消息。
   - Email：主题、第一封开发邮件、简短跟进邮件。
   - WhatsApp：首次联系消息、回复后的跟进消息。
4. 生成结果不再先集中英文、再集中中文。每个消息模块依次显示模块标题、英文编辑区和紧随其后的中文翻译编辑区。
5. 中文区域使用浅灰绿色背景，与白色英文区域区分；移动端上下排列且不横向溢出。
6. 每个消息模块提供“复制英文”和“复制中英双语”；页面顶部保留“复制全部英文”和“复制全部中英双语”。复制文本使用当前渠道的英文标题，不包含界面编号或按钮文字。
7. 保留旧消息字段并增加兼容转换。旧 LinkedIn、Email、WhatsApp 任务和旧版本仍可打开，不更换 localStorage key、不清空现有数据。
8. 重新生成、保存新版本、切换旧版本等现有行为必须继续工作。

## 验收要求

验证四渠道生成、Facebook 标题和内容、中英成对排版、各级复制、编辑、版本保存与重新生成、刷新持久化、历史显示/筛选/重新打开、旧数据兼容、移动端布局、Lint、TypeScript、生产构建和浏览器控制台。

本次不接入真实 AI、Supabase、登录或云服务，不增加重量级依赖，不执行 Git 提交或推送。
