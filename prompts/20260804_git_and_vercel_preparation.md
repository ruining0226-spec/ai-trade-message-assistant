# Git 初始化与 Vercel 部署基础整理

日期：2026-08-04

## 目标

- 在当前项目目录初始化本地 Git 仓库，但不暂存、不提交、不创建远程、不推送。
- 完善环境变量、构建缓存、测试输出、客户截图和临时上传文件的忽略规则。
- 在浏览器端压缩客户截图，并在调用现有分析 API 前限制整批请求大小。
- 补充本地运行、Vercel 环境变量、localStorage 和截图生命周期说明。

## 限制

- 不读取、打印或记录任何 API Key。
- 不改变火山方舟模型、接口地址选择方式、提示词或模型调用链。
- 不增加登录、数据库、对象存储或其他云服务。
- 不改变客户确认、开发信生成、单一结果保存和 AI 优化流程。
- 不执行 `git add`、commit 或 push。

## 主要修改

- 压缩前仍允许最多 5 张、原图单张最多 10MB。
- 浏览器使用高质量 WebP 和分级缩放压缩，压缩后单张最多 1.5MB。
- 压缩后整批文件最多 3MiB；超限时在创建请求前阻止提交并显示明确提示。
- 任务持久化继续只保留图片元数据，不保存 File、Blob URL 或 Base64。
- README 记录 Node.js、pnpm、本地环境变量和 Vercel 小范围试用要求。

## 验收标准

- `.env.local` 被 Git 忽略，`.env.example` 可以提交。
- 超限图片不会调用 `/api/analyze-customer`。
- 合规图片继续通过原有 multipart API 路径分析。
- lint、TypeScript 类型检查、自动测试和 production build 全部通过。
- Git 状态中没有被暂存的文件，也没有远程仓库。
